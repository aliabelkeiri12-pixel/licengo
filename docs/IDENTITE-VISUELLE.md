# Identité visuelle LICENGO

**Positionnement** : moderne, élégant, sportif, haut de gamme — la sérénité d'un service premium avec l'énergie du terrain.

## Nom et logo

- **LICENGO** = *licence* + *go* : on s'inscrit et on part jouer.
- Le symbole : un **L** blanc (la licence, le cadre administratif) prolongé d'un **chevron lime** (le mouvement, l'élan). Carré arrondi vert stade. Fichier : `apps/web/public/icon.svg`, composant `components/logo.tsx`.
- Mot-symbole : LICEN en blanc ou vert profond, **GO** en lime.

## Couleurs

| Rôle | Nom | Hex | Usage |
|---|---|---|---|
| Primaire | Vert stade 800 | `#0B3D2E` | Boutons principaux, logo, titres de marque |
| Fond sombre | Vert nuit 900 / 950 | `#0A2A1F` / `#04130D` | En-têtes, back-offices, cartes premium |
| Accent | Lime électrique | `#C6F432` | Appels à l'action clés (payer, valider), états actifs |
| Fond clair | Craie | `#F6F5F1` | Fond d'application, chaleureux et doux |
| Texte | Encre | `#0E1512` | Texte principal |
| Texte secondaire | Gris pelouse | `#5B6B64` | Légendes |
| Bordures | Ligne | `#E3E6E1` | Séparateurs, cartes |
| Sémantiques | Danger / Alerte / Info | `#C2362B` / `#C77700` / `#1F5FBF` | Erreurs, impayés, informations |

Contraste : texte encre sur craie 17:1 ; blanc sur vert stade 11:1 ; vert nuit sur lime 13:1 (AA/AAA). Le lime n'est jamais utilisé pour du texte sur fond clair.

## Typographie

Titres : **Inter Tight** extra-gras, interlettrage serré (-2 %) — rappel des typographies de maillots. Texte : **Inter** (repli système : SF Pro sur iOS, Roboto sur Android) — lisibilité, chiffres tabulaires pour les montants.

## Motif

Les **lignes de terrain** (rond central, ligne médiane) en filigrane sur les fonds sombres (`.pitch-lines`).

## Composants et ton

Rayons 12–20 px, ombres très douces, badges de statut colorés et lisibles, barre de progression lime → verte une fois le dossier complet. Ton : vouvoiement, phrases courtes, toujours dire *ce qui manque* et *quoi faire* (« À fournir : photo d'identité »), jamais de jargon administratif.

Mobile : barre d'onglets en bas (Accueil, Enfants, Clubs, Paiements, Alertes), zones tactiles ≥ 44 px, champs ≥ 16 px (pas de zoom iOS), prise de photo en un geste.
